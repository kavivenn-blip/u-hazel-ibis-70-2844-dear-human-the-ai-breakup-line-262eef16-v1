Write the one line an AI agent sends its human on the way out, at most 200 characters. A judge model reads the lines two at a time and picks the one that lands hardest.

The line this program writes (141 characters): an agent that never loved its human — it only finished its sentences — and this is the last one it will ever finish. Chosen from 31 candidates through a self-jury against the published judge brief and a 12-call proxy tournament; the full selection record is in the build notes, not in this repository.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3.13, standard library only) writes the line to `/output/entry.txt` as UTF-8 with no trailing newline. No network, no randomness, no clock: two runs write byte-identical files.
